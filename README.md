# mitomap-link

MCP server for [MITOMAP](https://www.mitomap.org) mitochondrial DNA variants (work in
progress). This initial commit carries only the data-release pipeline: a derived,
digest-pinned SQLite snapshot of the MITOMAP daily dump (CC BY 3.0), published by
`.github/workflows/data-release.yml`. Research use only; not clinical decision support.
